## Vue joins the catalogue — 19 September 2026

- Create native Vue 3 libraries with the same tokens, AI proposal workflow and saved versions as React.
- Vue components use TypeScript, Reka UI, v-model and slots. Exports, CLI and MCP deliver Vue source and framework-specific instructions.
- The catalogue and documentation now include Vue components, blocks and live Vue previews. Existing React libraries are unchanged.

## September 19, 2026 — A complete date-selection workflow

- DatePicker now supports single dates and ranges, two-month calendars, shortcuts, direct date entry, clearing and optional Apply/Cancel confirmation.
- Availability constraints, ISO week numbers, month/year navigation, inline display and French control labels share the same implementation in the Studio and exported source.
- Select supports multiple values; Combobox adds controlled search, disabled options and optional clearing. Form fields and file inputs preserve validation and native form behavior.
- Overlays accept custom triggers, tables expose loading and empty states plus custom cells, and external toast managers connect to their provider.
- New integration examples document the supported APIs and their limits.

## September 2026 — Early access foundation

CodeRocket UI starts a new product: create a design system, customize React components visually, review AI proposals and export editable source.

- Structured design-system model and semantic tokens.
- React catalogue built on Base UI, plus complete application and marketing blocks.
- Private libraries, account confirmation, password recovery and version history.
- Fumadocs documentation with interactive previews and Markdown for coding assistants.
- Source archives with compiled styles and MIT-licensed components.

This product is separate from **Vue Tailwind Datepicker**. The existing datepicker package and documentation remain available. At launch, React was the only Studio renderer. Vue support was added on September 19; Svelte and Solid remain planned.
