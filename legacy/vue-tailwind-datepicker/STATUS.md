# Frozen legacy source

Vue Tailwind Datepicker is no longer maintained. Its source, original MIT license, npm name, changelog and existing behavior are preserved for current users and forks. No fixes, feature work or releases are planned.

The existing `@coderocketapp/vue-tailwind-datepicker` release remains installable. It does not automatically migrate to CodeRocket UI. The new project currently supports React, not the historical Vue API.

The original repository tree was preserved from commit `91208cbd9be5465cc43ea3feb722305c476f9fb1`. Existing historical tags remain available. Root workflow automation now validates the new public core; nested legacy workflows do not run automatically.

The root Netlify configuration builds this folder's `docs/` so the historical documentation domain remains usable. Follow the root development guide to reproduce the frozen package or docs locally.
