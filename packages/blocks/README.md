# CodeRocket blocks

26 experimental interface patterns composed from `@coderocket/react`. MIT licensed. Import both style sheets:

```tsx
import "@coderocket/react/styles.css";
import "@coderocket/blocks/styles.css";
```

Blocks accept typed data and callbacks. They do not supply authentication, payment processing, email delivery or storage; previews demonstrate local interaction only. Build from the repository root with `pnpm build` and use the workspace package in a React consumer.
