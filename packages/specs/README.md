# CodeRocket specifications

MIT-licensed descriptions of catalogue components and blocks: states, variants, token bindings and accessibility notes. The `composition` entry validates bounded trees of supported primitives.

```ts
import { componentSpecs, blockSpecs } from "@coderocket/specs";
```

Editors, generators and coding agents can consume these specifications. They describe this repository's source; they do not grant permission to execute arbitrary generated code. Catalogue status is experimental.
